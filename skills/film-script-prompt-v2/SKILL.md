# 影视脚本提示词2.0

基于 SD2.5 提示词助手，把已确定的故事、人物、场景与镜头意图转成可直接复制的中文视频提示词。统一素材职责、视觉风格与镜头连续性，为分段生成后的剪辑保留清楚的连接。

## 工作范围与资料

- 默认中文；仅用户明确要求时提供英文。对白与画面内文字可另设语言。
- 提供新写、剧本／分镜转提示词、原稿优化、素材编排、续写、白模转成片和局部返修。调用本 Skill 本身只授权提示词工作，不自动上传素材、创建画布或消耗生成额度。用户同时明确要求生成时，按当前工具、任务范围和已有授权继续。
- 基础资料是截至 2026-10-23 的 Seedance 2.5 手册整理快照；本版结构、声音默认值及时长规划依据用户 2026-11-07 的要求。来源与平台边界见 [model-notes.md](references/model-notes.md)。不把创作建议说成官方强制语法或当前全平台实测结论。
- 普通写稿可离线完成；询问当前规格或实际执行时，再核对所用平台的支持情况，不把即梦的其他模式直接当作第三方入口能力。
- 按具体任务读取 [task-patterns.md](references/task-patterns.md)；需要完整写法时读 [examples.md](references/examples.md)。参考文件均随本 Skill 提供，不依赖原 Skill 的安装路径。

## 先利用已有上下文

区分新建短片、优化原稿、参考视频迁移、续写、已有视频编辑、两段衔接、白模转成片和多宫格分镜。新建内容再区分一镜到底与多镜头。

先从对话、剧本、附件与已有成果确定人物身份、服饰、事件、场景、画幅、总时长、素材职责、视觉方向及声音要求。沿用已确认内容，不另起一套故事或风格；剧本明确的身份、服饰与情境优先，不让参考照片的姿势或背景覆盖剧本。

- 信息足够就直接写。只有缺失项会明显改变结果才集中问 1—3 个问题，例如要改哪个人物、续写到总长多少、冲突台词以哪版为准。
- 只有一句模糊想法时，可自行选择一个清楚的方向写可修改草案；时长根据事件和动作规划。画幅也未给且无法从用途推断时，可暂按16:9，在提示词外简短说明假设。完全没有创作内容时，请用户提供想法、原稿或素材之一。
- 素材先查看实际可访问内容；无法查看的视频或音频，只能按用户描述工作并说明依据，不假装已分析。
- 尊重用户指定时长、镜头形式与关键内容。密度过高时调整生成分组或说明必要取舍，不擅自缩短全片或删除关键镜头。

## 单次生成与镜头时长规划

按 Seedance 2.5 单次生成 **4—30秒** 规划，常规优先把**一次生成的视频总时长安排在25秒以下**。按叙事、动作、对白及连接需要决定长度，不为用满额度拉长停顿。

- 分清**全片总时长、单次生成总时长、单个镜头时长**。一次生成可以包含一个或多个镜头；25秒以下约束的是单次生成总长，不是要求每镜接近20秒，也不意味着单镜至少4秒。
- 一个8秒生成段可以由2秒、3秒、3秒的三个镜头组成；一个6秒连续动作也可独立生成。镜头数量与长度服从内容，不固定每5秒切镜。
- 需要保持动作连续、实现特殊衔接，或镜头间衔接要求较高时，可采用 **25—30秒** 的单次生成，并简短说明连续生成的理由；最长不超过30秒。25秒及以上不作为常规默认，也不为了压到25秒以下拆断必要的动作链。
- 全片较长时，先按故事和连续性划分生成段，再安排段内镜头。不同生成段写清前段结束与后段开始的人物位置、朝向、动作、道具及镜头状态；对确实需要的动作接力、视线或遮挡衔接具体描述。
- 每个生成段单独计算时间轴，通常从0开始，末端等于本段总长。续写明确新增时长与最终总长，不能把“延长到25秒”写成“新增25秒”。
- 若实际入口不支持所需时长，说明该入口限制并给出分段方案；超过30秒的全片也按分段生成规划，不从旧手册的超长模式推定本任务可一次生成。

## 提示词固定输出结构

每个可独立提交的生成段，用一个完整代码块，按以下四个标题及顺序输出；不把绑定说明或负面要求拆到另一个提示词块。声音写入【画面描述】，不另加第五个一级段落。四段结构固定，段内表达随情境组织。

### 【素材绑定】

明确每份参考素材的用途、绑定对象及作用范围，锁定人物、环境、产品或其他必要视觉特征。

- 沿用用户实际素材及平台标签，使用一致的 `@图片1`、`@视频1`、`@音频1` 等称呼。例如：“环境参考图1（@图片1）用于锁定场景建筑外观、空间布局与材质；不引入图中的人物。”
- 分清角色外貌、服饰、产品结构、环境、构图、动作、运镜、节奏、音色等职责；只作分析的素材不擅自绑定为生成参考。参考有冲突时，按已确认用途明确优先级。
- 三视图中的多个角度属于同一人物；人物照片的姿势不覆盖动作视频；环境图中的人不自动加入演员名单。产品图重点锁定轮廓、比例、材质、原色、结构与标识。
- 只引用已提供或明确计划使用的素材。缺少必要素材时，在块外说明缺口及拟用编号，标为待绑定；不虚构附件，也不把文字编号说成已完成平台绑定。实际上传和选择引用仍需在执行平台完成。
- 无外部素材也保留本段，简写“无外部参考素材；人物与场景按下文文字设定”，不强凑图片或音频。

### 【视觉风格锁定】

依据上下文已确定的方向，统一各镜头的色彩、影调、光线、材质、画面质感与情绪；只写影响当前画面的特征。跨生成段沿用共同规则，可按场景需要具体说明变化原因，不让每镜随机换一种风格。

已确认方向不重新发散。未确定时，可根据故事提出一个明确、可修改的暂定方向，并在块外说明。用可见条件表达风格，例如光线方向、反差、冷暖关系、皮肤与金属的质感，不堆叠“高级、震撼、电影感”等空泛词。

### 【画面描述】

把叙事内容、景别、机位、透视、人物动作、镜头运动、持续时间及衔接方式组织成可拍的过程。这些是编写方向，**不要求每镜逐项填写或机械套表**；简单动作可以用自然段，复杂节拍再分时间区间。

- 先写本段时长、镜头形式及主体正在做什么，再展开必要细节。人物无外观参考时补足辨识特征；有参考时避免重复堆整套五官。
- 动作写清起始状态、过程、结束状态及环境反馈；多人互动明确谁对谁做什么、站位与反应。承接上一镜的位置、道具与动作，避免无解释地重新摆场。
- 用可见表演表达情绪，例如视线、呼吸、重心、手部动作；关键变化写清先后与时机，给对白、停顿和反应留真实时间。
- 需要时间轴时可用 `[00.0-03.0s]` 连续区间，或明确的事件开始点；时间戳是编排建议，不是逐帧控制语法。单镜头内部也可以有多个动作节拍。
- 一镜到底写明连续相机路径、起终点、景别与速度变化，不能在后段混入反打、跳切或机位重置。多镜头明确切换位置和连接依据，按情境使用硬切、动作匹配、遮挡或其他衔接，不一律禁止切镜。
- “固定镜头”说明是位置和朝向都不变，还是只保持朝向、允许横移。复杂运动写具体从哪到哪及快慢变化。
- 对白、旁白、环境声与动作音效在本段内安排；字幕、招牌、产品标签和片尾文字分别规定。保留品牌标识不能同时要求所有文字消失。

### 【负面提示词】

明确本镜头或本生成段禁止出现、需要避免的内容；只列与任务相关的约束，并与前文正向目标一致。多镜头有局部禁项时指出对应镜头，不让局部要求误伤整段。

例如锁定人物数量与服饰、避免特定道具凭空出现、禁止一镜到底中跳切，或禁止新增字幕。无用户配乐要求的新建内容写明“不添加背景音乐”；无配乐不等于禁止对白、环境声或音效。不追加与当前问题无关的通用负面词长清单。

## 声音设置

**用户未明确要求时，默认不添加背景音乐，可按画面需要配置环境声和动作音效。** 短片通常要在生成各镜头后剪辑，各段独立配乐容易在拼接时不连续或相互干扰，背景音乐默认留待后期统一处理。该说明放在工作安排中即可，不必每次在提示词里解释原因。

- 在【画面描述】中简写声音方案，如“保留脚步、衣料摩擦与房间环境声；无背景音乐”，并在【负面提示词】中保持一致。不因出现音频参考或参考视频含音乐，就自动加入配乐；音色、节拍参考与使用原配乐分别判断。
- 用户已明确要求音乐时按其要求安排，区分要在本次生成中合成还是后期统一添加；已确认的音乐要求不重复询问。不擅自为剧本添加对白或旁白。
- 有对白时写清说话者、准确台词、语言、语气、进入时机及音色引用。无音频参考可用文字描述音色，不虚构引用；台词和开口动作对应当前说话者。
- 编辑已有视频时，保留未要求改变的原声，包括已有配乐；“默认不添加”不授权删除原配乐。“去BGM”也不等于删除对白、笑声或环境声。
- 无BGM不等于静音，无字幕不等于无对白，也不等于删除产品标签。准确文字和口型是生成目标，需要成片验收，不承诺已验证的逐字或逐帧准确。

## 优化与返修

保留故事、已确认风格、台词、素材职责与镜头意图，优先修正歧义、矛盾、动作连接及任务密度。改成四段格式时保留有效原意，不借格式调整另写创意。

按用户指定的图片、镜头、时间或元素定位问题，仅修改相关描述，检查前后连续性并同步受影响的段落。区分提示词问题、缺少参考与实际生成波动；未看到失败结果时写“根据反馈推测”，不保证改词必然修复。

## 交付与检查

单个生成段默认先用一两句话交代画幅、时长和关键安排，再给含四段标题的完整提示词代码块。素材绑定正文保留在块内。用户说“只要提示词”时仅给所需文本。

整套脚本按生成段分别给可独立复制的完整四段提示词，块外标注对应镜头、段长及必要连接说明；每段带上自身需要的素材与风格，不要求用户拼接散落规则。不默认附多个创意候选或长分析。

输出前内部检查：

1. 单次生成总长为4—30秒，常规优先低于25秒；25—30秒有叙事、动作或连接理由。没有把单次生成总长当成每镜时长或把4秒误作段内每镜下限。
2. 全片总长、各生成段总长、段内时间轴及模式一致；续写分清新增与最终总长，无意外空档或重叠。
3. 每段均按【素材绑定】【视觉风格锁定】【画面描述】【负面提示词】输出；素材存在或已标待绑定，角色称谓、人数、服饰、产品与道具一致。
4. 共同风格与已确认方向一致；动作、运镜和跨段状态可承接，一镜到底无矛盾切镜；编辑限定目标、范围和保留项。
5. 未明确要求配乐的新建内容不添加BGM；对白、环境声、音效与文字约束不冲突；不误删原片已有声音。
6. 没有把“4K、60fps、Octane”等视觉诉求当成真实导出参数，没有承诺绝对一致、逐帧精准或无损音频分离。

结构检查通过不等于模型效果验证；只完成提示词时，不声称已经生成或测试视频。
