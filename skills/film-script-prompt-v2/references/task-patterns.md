# 按任务选择写法

只读当前任务相关部分。以下是基于手册提炼的写作方法，不是模型强制模板。所有路径最终都按主文的【素材绑定】【视觉风格锁定】【画面描述】【负面提示词】四段输出；下列顺序是段内组织提示，不另建替代模板。无外部素材时也保留素材绑定段并说明。

新建内容默认无背景音乐，可配置环境声和动作音效；已有视频编辑保留未要求改变的原声。按单次4—30秒、常规优先低于25秒规划；25—30秒须有连续动作或衔接需要。此限制针对单次生成总长，段内单镜可以更短。

## 新建短片：单镜头或多镜头

素材职责放入【素材绑定】，共同色彩、光线与质感放入【视觉风格锁定】；【画面描述】组织故事概述、动作节拍／分镜及声音；【负面提示词】列当前段的禁项。

每段优先交代主体、动作、镜头和状态变化，再按需添加声音。镜头数量与动作密度服从时长，不强制30秒或每5秒一镜。

- 一镜到底：摄影机有连续路径、起终点及速度变化。可以分秒安排动作，不因换时间段而切镜。穿门、绕物、进入水下等改变空间时，交代实际移动与遮挡关系。
- 多镜头：写景别与切换方式；转场由动作、视线、声音、遮挡或共同形状解释。用户要求硬切时保留，不套用“禁止切镜”。
- 多人：稳定编号、人数、站位与交互对象。主角、配角、背景群像可按镜头使用，不强迫每镜都全员同框。
- 产品广告：锁定轮廓、比例、配色、标识和关键结构；让灯光、材质与运动服务卖点。未知底部或背部不能编成已知事实；若由模型补全，明确为创意推演或待补参考。
- 细腻表演：用视线、呼吸、嘴角、吞咽、手部等可见变化表达情绪；明确关键变化的先后，少用抽象情绪词代替动作。

## 较长全片的分段生成

分清全片总长和单次生成总长。即便 [model-notes.md](model-notes.md) 留有旧手册超长模式记录，本版仍将较长全片拆成单次不超过30秒的生成段，多数段优先低于25秒。

先按故事节拍划分生成段，再把段内镜头按实际动作、对白与剪辑需要分配时间。不要将每个镜头都安排在20秒附近，也不必每段接近25秒。确需25—30秒的段落注明连续生成的理由。

每段独立输出完整四段提示词。跨段继承角色脸、发型、服装、体型、贯穿道具、共同风格与声场；写清前段末态和后段起态的连接。场景可以变，线索与角色状态需承接。对白和动作音效按各段需要生成，背景音乐默认留待后期统一处理。

不为凑时长机械复制动作，也不为压到25秒以下拆断必要的连续动作。低事件密度的长镜头可依靠环境微动、焦点转换、光线与声场变化推进，但仍按内容需要决定时长。当前平台限制不同则据实调整方案，不承诺跨段绝对一致。

## 视频延长／续写

先确认原片长度、末态与所需新增长度；“延长到25秒”表示目标总长，不能误写为新增25秒。

【素材绑定】指定目标视频及外观／音色参考；【视觉风格锁定】继承原片；【画面描述】写新增X秒、最终总长、原片末态、新增动作及声音承接；【负面提示词】限定不能改变的原片要素和当前禁项。

- 只描述新增段，不重拍原片。新增时间轴可从0计时，但要标明“以下时间相对新增段”；绝对时间轴则从底片结尾开始，二者择一。
- 同镜头续写：继承末帧的姿态、速度、镜头、空间与声场，写清下一动作及结束状态。
- 切镜续写：写A镜尾态、转场机制、B镜起态及连接理由，不能同时全局禁止所有切镜。
- 连续延长使用最新完整视频。依据手册检查底片≤30秒、新增4—30秒、总长≤60秒；当前平台规则不同时按实际支持处理。
- 原片长度不明时，不编造总长。先写新增内容，或在必须确定设置时提出最少问题。向前／向后延长的界面支持应另核对。

## 已有视频编辑与局部修改

【素材绑定】指定待编辑视频及替换素材；【视觉风格锁定】保留未要求改变的原片风格；【画面描述】写对象、位置、原状态到目标状态、生效时间、保留项及遮挡／运动中的持续要求；【负面提示词】限定修改范围，避免无关改动。

示意：`在@视频1第7—15秒，将画面左侧红框中的羊替换为棕马，沿用该对象的运动轨迹、接地位置与遮挡关系；其他人物、镜头、场景及声音保持原样。`

- 不存在实际框选时，不谎称已有红框；用清楚位置或建议用户标注。
- 标注来自00:00，不代表只改该帧或自动全片生效；文字要明确全片还是哪个时间范围。
- 同名物体有多个时指明目标，如桌面的备用筷子，不误删手中正在使用的筷子。
- 删除：自然补全被遮住的背景、阴影及接触处。替换：补足大小、材质、受光和遮挡关系。改色：保留纹理、褶皱和材质。
- 多项编辑可用简短“修改／保留”清单。局部返修要限定时间和对象；不要顺手改未要求的色调、服装或镜头。
- 换机位：指定新机位、景别与运动，补充新角度将显露的结构，同时保持主体和原事件节奏。新视角不应和“构图逐像素不变”同时提出。
- 纯声音编辑：写清移除哪些声音、保留哪些声音及画面是否不变；“去BGM”不代表删除对白、笑声或环境声。不承诺采样级无损。

## 参考视频的创意迁移

明确继承的是动作、表情、镜头、喜剧机制、节奏或转场，并说明要替换的主体、场景或内容；不要用“完全参考”包办全部职责。

例如，保留“手指划动触发屏幕内容变化”的交互机制，替换屏幕图像；或保留变身的准备—旋转—揭示节拍，把目标服装、道具和外观绑定到新图。

## 两段视频之间生成过渡

【素材绑定】区分前片与后片；【视觉风格锁定】说明两段的风格承接；【画面描述】写前片末态、共同视觉／动作锚点、中间动作、后片起态及声场连接；【负面提示词】限定不应出现的突变和无关改动。

尽量共享运动方向、镜头速度、形状、亮度或颜色中的一项。形状匹配时明确位置、大小、方向及材质怎样渐变；动作接力时写清起跳、遮挡和落地的承接。

没有原片末态和起态时不能声称已经设计出精确衔接；可按用户描述先写候选。不能把“保留原片”写成已经完成或逐帧未改的事实。

## 白模／三维预演转成片

先决定白模到底约束什么：仅空间与体型关系，还是还要严格继承动作、运镜、节奏和光线。不能默认把用户原本只想参考的内容全部锁死。

- **粗白模**：【素材绑定】声明职责及几何体／颜色到角色、道具、建筑的对应映射；【视觉风格锁定】定义场景和材质；【画面描述】组织完整动作链、收束与声音；【负面提示词】限定不能改变的运动或结构。
- **细白模**：【素材绑定】明确将白模动画转为最终画面及各参考分工；【视觉风格锁定】统一最终质感；【画面描述】按需要分时段描述画面、运动与声音；【负面提示词】列保持项及禁项。
- 角色／产品参考只管外观时，不继承照片姿势、背景或画面中的多视图排版。
- 动作视频只用于局部时，写明如“仅在20—25秒参考@视频2”，并规定其他时段不照搬；参考冲突时明确各自优先级。
- 给几何体写具体可追踪映射，不泛称“把白模变好看”。补足服装、头发、液体等次级运动及不同环境受力。
- 需要最终视觉时写清不保留灰色预览质感；用户本来就要白模预演时则保留白模。
- 材料准备可建议去除轨迹线、坐标轴与相机锥。手册当时称粗白模效果较好，且对带四肢／翅膀的粗模型有谨慎建议；遇到这类素材优先补清完整动作，不据此一概禁止。
- 不推定 C4D 插件可用，也不把“PBR、Octane”写成实际渲染流程。

## 多宫格故事板

【素材绑定】说明图的职责、格数、阅读顺序及人物／道具外观；【视觉风格锁定】统一各格转成片后的画面；【画面描述】组织故事概述、逐镜时间、景别、动作、格间连接与声音；【负面提示词】规定不保留的网格、编号及其他禁项。

确认每格是一个镜头、一个动作阶段还是同一角色的设定视图。多宫格不应在最终视频里保留分屏网格，除非用户要求。火柴人和线稿只提供走位、构图或事件顺序，不覆盖独立角色外观。

实际图8格而脚本9镜时，标明新增加的收尾，不假称原图有9格。需逐秒控制时由文字分配时长，补足格与格之间发生的动作，避免把分镜当静态轮播。

## 对白、音色与多语言

用 `角色／外观引用 → 站位与动作 → 台词 → 音色引用 → 语气与时机` 绑定多人对话；避免“他们说”或连续台词不指明说话者。

中文提示词可以要求其他语言对白。分别确定指令语言、对白语言、字幕语言、场景文字语言；已有确认台词直接保留，不擅改措辞。音频清晰、少噪声更利于作音色参考；未提供音频就用文字形容音色，不虚构 `@音频1`。

必要时将字幕与招牌、标签、片尾分开规定。生成准确文字和口型是目标，不保证逐字、逐帧正确。

## 绿幕与前景合成

区分“把背景换成纯绿以便后期抠像”和“把绿幕前景融合进目标场景”。前者只改背景并保留主体动作；后者绑定前景、承载背景、出现时机、动线、尺度、透视、遮挡、接地与统一受光。

天气参考仅负责天气和受光时，不让它覆盖场景建筑。用时间顺序描述前景经过、事件触发和环境反应，避免简单堆素材。残绿、边缘和融合质量需在成片中验收。
