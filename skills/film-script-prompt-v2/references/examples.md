# 四段提示词完整示例

以下为写法示范，非官方原文、非生成实测。素材编号仅在各示例内部有效，实际使用需有对应素材并在平台绑定。示例题材、画幅、风格与时长不作为所有任务的默认模板。

## 1. 无外部素材：8秒生成段内的三个镜头

用户想做一段简短写实咖啡产品画面。规划一次生成8秒，内部三个镜头分别2秒、3秒、3秒，说明单次总长与单镜时长的区别。界面按实际入口设置8秒、16:9。

```text
【素材绑定】
无外部参考素材。主体为一只无文字的白瓷咖啡杯，配一把金属小匙，置于浅色木桌；三镜沿用同一杯子、小匙与桌面。

【视觉风格锁定】
写实产品摄影，清晨暖阳从画面左后方照入，浅色木桌和背景窗户保持柔和暖调。白瓷、金属与咖啡液体保留各自的真实反射，蒸汽薄而透亮，背景自然虚化。

【画面描述】
生成一段8秒、16:9的咖啡产品短片，包含三个镜头。
[00.0-02.0s] 杯沿和咖啡液面的特写，机位略高于杯口，摄影机缓慢靠近；液面有轻微波纹，一缕细薄蒸汽升起。
[02.0-05.0s] 硬切到杯身左前方的近景，摄影机贴近桌面沿杯身向右横移，高光从杯身左侧缓慢滑向正面；杯子和小匙保持静止。
[05.0-08.0s] 硬切到略微俯视的三分之四角度中近景，摄影机缓慢拉远，让杯子、小匙及一小片桌面完整进入画面，最后自然减速落幅。各镜保持杯柄朝向、小匙位置和光线方向一致。
保留很轻的室内环境声，无对白，无背景音乐。

【负面提示词】
不添加背景音乐、字幕或新增标识；不新增倒水、搅拌动作或其他道具；杯子形状、杯柄朝向及小匙位置不在切镜时改变，蒸汽不形成浓烟。
```

## 2. 白模负责运动，图片分别负责产品和视觉风格

假定已提供：`@视频1`为15秒白模预演，`@图片1`为黑盖透明方瓶产品，`@图片2`为已确认的灯光与色彩参考。一次生成15秒。

```text
【素材绑定】
@视频1用于锁定全片运镜、产品位置、旋转轴向、旋转速度、台面及背景体块关系；将主体方盒映射为香水瓶。@图片1仅锁定香水瓶外观、比例、黑色瓶盖、液体颜色与瓶身标识，不继承拍摄机位。@图片2仅提供奶白背景、浅金轮廓光和柔和反射，不引入其中其他产品或文字。产品结构以@图片1为准，运动以@视频1为准。

【视觉风格锁定】
沿用已确认的奶白与浅金产品视觉，背景干净，条形柔光在透明玻璃上形成清楚而不过曝的反射，玻璃边缘显出厚度。全片保持同一组灯光、材质与反差关系，最终呈现完整商业产品画面。

【画面描述】
将@视频1转换为一段15秒、16:9的香水广告，保持预演原有镜头形式及连续路径。
[00.0-05.0s] 沿用预演的开场构图与缓慢推进。香水瓶底部落在预演主体的同一台面位置，黑色瓶盖和液体高度与产品图一致，浅金轮廓光显出玻璃边缘。
[05.0-11.0s] 继续按@视频1的旋转节奏及相机路径运动，柔和条形高光随既定视角滑过瓶身，台面倒影与接触位置稳定，标识随瓶身透视自然变化。
[11.0-15.0s] 沿用预演的减速与落幅，停在同一最终产品展示构图，轮廓光和玻璃折射连续，结尾保留短暂展示。
仅配置轻柔的产品移动音效，无对白、无背景音乐。

【负面提示词】
不添加背景音乐、字幕或新道具，不改变瓶身比例、瓶盖结构、液体高度和标识位置；不将黑盖改为银盖，不额外增加产品转向，不保留灰色白模质感。
```

## 3. 原片18秒，续写7秒，最终25秒

假定`@视频1`为已提供的18秒原片，少年末尾仍在滑行。此次新增7秒；最终25秒不是单次生成25秒。时间轴相对新增段从0开始。

```text
【素材绑定】
@视频1是18秒原片，用于锁定少年外貌、发型、服装、滑板、滑板场以及末尾的姿态、滑行方向、速度与跟拍距离。新增内容承接其末态，不重拍原片。

【视觉风格锁定】
继承原片的时间、光线方向、色温、曝光、材质和画面质感，新增段不另加滤镜或改变天气。

【画面描述】
向后续写7秒，保留已有18秒内容，最终总长25秒。以下时间轴仅描述新增的7秒，以一个连续跟拍镜头承接原片。
[00.0-03.0s] 少年沿原方向自然滑行，平稳降低速度，上身慢慢转向摄影机，视线看向镜头；摄影机继承原末尾的运动方向与距离。
[03.0-05.0s] 少年露出轻松微笑，保持双脚与滑板的接触和身体平衡，摄影机随滑行自然减速。
[05.0-07.0s] 少年抬起右手轻轻招手，再将手放下，滑板继续短距离向前移动，以自然表情收尾。
延续原片现场声，不添加背景音乐、对白或旁白；新增滑板滚动声与减速动作对应。

【负面提示词】
不额外添加背景音乐或字幕，不切换场景、重置机位或凭空增加人物与道具；人物外貌和服装不变，双脚不脱离滑板，新增段不改变原片已有内容。
```

若原片已带配乐且用户未要求去除，续写方案应处理已有声音的承接，不将“默认不添加配乐”误用为删掉原配乐。

## 4. 仅编辑原片6—10秒的裤子颜色

假定已提供12秒原片，可识别画面中间的滑板少年，用户只要求局部改色。没有实际框选就不写“红框”。原片已有声音，包括音乐，均在保留范围内。

```text
【素材绑定】
@视频1为12秒待编辑原片。目标仅为画面中间滑板少年穿着的卡其色裤子；人物身份、其他服饰、滑板、背景、原有文字及声音均沿用原片。

【视觉风格锁定】
保留原片色调、光线、对比、画面质感与人物肤色。改色后裤子的黑色仍随原有光照呈现明暗，不将整段重新调色。

【画面描述】
仅在原片第6—10秒，将目标裤子由卡其色改为黑色，保留原有版型、褶皱、材质与光照层次。黑色随腿部运动、裤褶和遮挡持续变化，边缘贴合裤子轮廓。
第6秒之前和第10秒之后保留原裤色；这是一段时间内的局部改色，不是从6秒开始持续变黑。全片人物动作、摄影机运动、滑板轨迹、背景、字幕及已有声音保持原样，不添加新声音。

【负面提示词】
不修改6—10秒以外的画面，不替换人物或服装版型；黑色不闪回卡其色，不溢出到皮肤、上衣、鞋或滑板；不添加、删除或替换原片音乐、对白和环境声，不做其他无关修改。
```

用户若想从6秒开始持续变黑，应改为“第6秒至片尾”；不希望边界直接变色时，按用户意图补充过渡，不机械沿用局部范围。

## 5. 双人对白与两种音色

假定已提供两张人物图和两段音色参考；两张人物图分别对应两个人，各图内的多视角不代表多名演员。一次生成10秒。

```text
【素材绑定】
@图片1锁定左侧短发女子的外貌与服装，@图片2锁定右侧戴眼镜男子的外貌与服装；各图中的不同角度属于同一人。女子使用@音频1的音色，男子使用@音频2的音色；两段音频仅参考音色，不使用原台词或背景声音。

【视觉风格锁定】
沿用已确认的暖色咖啡馆方向，窗光柔和，皮肤保留自然质感，木桌与背景维持温暖低反差，表演安静克制。

【画面描述】
生成一段10秒、16:9的双人咖啡馆对话。两人坐在同一张小桌两侧，保持双人中景，摄影机缓慢靠近，全程不切镜。
[00.0-04.0s] 左侧女子看向男子，轻轻握住杯子，用普通话、平静但有期待的语气说：“你还记得这里吗？”男子听她说完，不抢话。
[04.0-06.0s] 男子短暂停顿，抬眼看向女子，表情从思索转为轻松。
[06.0-10.0s] 右侧男子用普通话、温和低沉的语气回答：“当然，第一次见面就在这里。”女子安静听完，嘴角露出微笑。
开口动作对应当前说话者，保留轻微室内环境声和衣料摩擦，无背景音乐。

【负面提示词】
不添加背景音乐、旁白、字幕或新增画面文字；两人的脸、发型、服装、座位及音色不互换，不增加第三名人物，不在停顿时让两人同时开口，不切镜或重置机位。
```

## 6. 连续动作确有需要时采用27秒

假定已确认27秒一镜到底：演员推开卡住的门，抱箱穿过狭窄走廊，在终点放下箱子。门的阻力、身体负重及狭窄空间通过连续表演建立因果，镜头需保持跟拍和身体遮挡的空间关系，因此整体一次生成27秒；不为了低于25秒拆断。人物与环境素材已提供。

```text
【素材绑定】
@图片1用于锁定女演员的外貌、发型与深蓝工装，@图片2用于锁定门口、狭窄走廊和终点房间的空间与墙面材质；不引入环境图中的其他人物。纸箱为无文字的棕色瓦楞纸箱，开场已经抱在演员怀中。

【视觉风格锁定】
沿用已确认的写实室内风格，窗外冷色日光与走廊略暖的顶灯自然混合，墙面与衣料保留朴素纹理，反差克制；人物穿过空间时受光随位置连续变化。

【画面描述】
生成27秒、16:9的一镜到底片段。摄影机位于演员后方偏右，保持能看见她的上半身、纸箱和门框的中景距离。
[00.0-07.0s] 演员抱稳纸箱，用左肩缓慢顶开卡住的门。门起初只开一条缝，她调整重心再次发力，门才逐渐打开；摄影机随她向前靠近，不绕到门的另一侧。
[07.0-18.0s] 她侧身护住纸箱穿过门口，右侧箱角先过门框，身体随后进入。摄影机沿同一路径跟进，再随她恢复正身，沿狭窄走廊稳步前行；呼吸和步伐体现负重，不停下来重新抱箱。
[18.0-24.0s] 她走进终点房间，转向左侧桌面，屈膝并将箱子轻轻放下。摄影机沿其右后方划出短弧线，持续看见双手和箱子接触桌面的过程。
[24.0-27.0s] 她确认箱子放稳，松手后缓慢直起身，呼出一口气；摄影机自然减速停在侧后方中景。
保留门轴受力声、脚步、衣料摩擦、纸箱接触桌面的声音和轻微呼吸，无对白、无背景音乐。

【负面提示词】
不添加背景音乐、字幕或其他人物，不切镜、跳切或突然重置机位；不让纸箱穿过门框，不让纸箱在手中变形或消失，不在放稳之前松手，不把走廊改成开阔空间。
```

27秒只服务本例的连续表演与空间衔接。简单推门或普通走路应按所需节拍缩短，不照搬该长度。
